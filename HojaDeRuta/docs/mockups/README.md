# Mockups ilustrativos

Esta carpeta contiene mockups funcionales de apoyo para la documentacion del usuario final.

Alcance:
- estan basados en la estructura visual actual de la aplicacion
- sirven para explicar pantallas, acciones y validaciones
- no deben considerarse evidencia exacta de ambiente productivo

Uso recomendado:
- incluirlos en el manual funcional
- reemplazarlos mas adelante por capturas reales cuando se defina esa etapa

Archivos incluidos:
- `pantalla-inicial.svg`
- `formulario-hoja.svg`
- `flujo-revision.svg`
- `modal-rechazo.svg`
- `modal-auditoria.svg`
- `panel-notificaciones.svg`
- `alertas-validacion.svg`
